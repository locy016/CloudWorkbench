# 云端工作台 Android 开发计划

手机和平板用于查看云端 Codex 任务、处理审批、继续会话和检查服务器。现有功能通过专用 SSH 密钥访问固定业务网关。下一阶段优先缩短 APP 内的常用操作路径。

## 0.4.50 资讯入口验收

「服务器数据」默认打开资讯，先展示联合国日内瓦要闻。时事收录欧盟委员会通报，经贸收录 WTO 新闻和英国商业与贸易动态。来源、发布时间、摘要和原文地址在原生页面展示。经贸指标与参考汇率从同页进入。

0.4.50（构建号 63）已发布至私有更新源，TB322FC 已同签名升级。网关 38 项、模拟器 29 项和正式包真机 5 项测试通过。真机确认进入页面自动加载要闻，时事和经贸入口可切换和取数，CSV、JSON、欧元参考汇率与世界银行指标通过回归。私有更新源已核验完整 APK 的 SHA-256 与首尾分段响应。

## 0.4.49 贸易及物流资源验收

按需资源支持 RSS、Atom 和 CSV，以及关键词和 UTC 日期筛选。生产接口已验证 WTO 新闻、NWS 海运气象警报和 NOAA 港口潮位。一次纽约测站查询匹配并可下载 719 条，APP 预览 100 条。

0.4.49（构建号 62）已发布至私有更新源，TB322FC 已同签名升级。网关 36 项、模拟器 28 项和真机正式包 4 项验收通过。真机验证了 WTO 关键词筛选、NWS 警报预览和 NOAA 指定 UTC 日期的 CSV 导出，也通过了 JSON 下载、欧元汇率及世界银行贸易查询回归。私有更新源已核验完整 APK 的 SHA-256 和首尾分段响应。

## 0.4.48 按需资源验收

「服务器数据」可从服务器目录选择已注册来源，填写筛选条件、实时获取并保存 JSON。服务端更新目录后，APP 刷新即可读取。生产接口已验证全球地震动态、开源发布记录和公开项目搜索。网关 34 项测试和模拟器查询及保存测试通过。TB322FC 正式包通过实时数据获取、关键词搜索、JSON 导出及汇率和贸易回归。0.4.48（构建号 61）已发布至私有更新源，完整 APK SHA-256 和首尾分段响应已核验。

## 0.4.47 国际贸易验收

生产服务器复测世界银行官方指标 API。国家目录和多组国家、年份请求返回 HTTP 200，Node.js 直连样本耗时 31 至 552 毫秒。此前 DNS、TCP 和 TLS 建立后等待 HTTP 响应超时的现象未再出现。网关使用固定接口并缓存同一国家、年份的结果。

0.4.47（构建号 60）已发布至私有更新源，并同签名升级到 TB322FC 平板。网关 31 项测试、真机 26 项独立回归和正式包 3 项浏览页验收通过。新功能在真机上验证了中国 2023 年、美国 2024 年和日本 2026 年暂无数据的场景。按 APP 抓到的 102 个数据包均属于到工作台的 SSH 连接。私有更新源的完整 APK SHA-256 和首尾分段响应均通过核验。

## 0.4.46 浏览页服务器数据验收

0.4.46（构建号 59）已发布至私有更新源，并同签名升级到 TB322FC 平板。网关 27 项测试、真机 26 项独立回归和正式包 2 项浏览页验收通过。私有更新验证覆盖完整 APK 的 SHA-256 和首尾分段响应。

- 正式包打开「浏览 → 服务器数据」并手动刷新，确认显示欧洲央行、数据日期和参考汇率。按 APP 抓取的 82 个数据包均属于工作台 SSH 连接。

## 0.4.45 服务器概览验收

0.4.45（构建号 58）已发布至私有更新源，并同签名升级到 TB322FC 平板。网关 23 项测试、平板独立验收 26 项测试通过，覆盖手动刷新、异常排序、采集时间变化、刷新失败及断线后的上次状态。

- 用原 SSH 绑定验证了生产概览、手动刷新时间和最近异常摘要。正式包跨进程测试确认离线可查看上次采集的概览。真机从私有更新源读取发布清单，并校验首段 64 KiB 与签名 APK 一致。
- 完整正式包下载后的安装交接及真实语音输入可在真机继续回归。

## 开发顺序

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| 已发布的基线 | 退役旧配对入口。0.4.42 支持任务续接、草稿与待发图片恢复、短时后台切换复用 SSH 连接 | 同签名升级后原密钥可继续连接。回归覆盖重连、分页、草稿恢复和同请求重试。真机已验证正式包分段响应 |
| 核心状态已发布 | 通过请求编号核对回执。概览指标独立刷新，会话和审批继续同步 | 回执丢失且任务随后执行失败时，独立显示已接收和执行失败。指标阻塞或返回错误时仍可处理审批 |
| 首页任务入口已发布 | 「继续任务」直达具体待审批或待回答请求。「最近任务结果」显示最近五个有结果的会话 | 从首页一次点击到对应审批或最新结果。已处理审批从首页移除 |
| 历史搜索和继续草稿已发布 | 历史会话支持跨分页的标题关键词、项目和状态组合筛选。首页按编辑时间展示未发送草稿 | 搜索可直接命中第 41 条以后的会话，继续翻页保留筛选条件。重开 APP 后可在首页继续项目或会话草稿 |
| 服务器概览已发布 | 手动刷新、异常服务优先、采集时间、上次采集状态和最近异常的只读摘要 | 异常排序、刷新后采集时间变化、断线和跨进程查看上次状态均通过真机验证 |
| 浏览页服务器数据已发布 | 经现有 SSH 连接读取欧洲央行参考汇率，显示数据来源、数据日期和上次数据状态 | 正式包真机验证首次打开和手动刷新，抓包确认只连接工作台服务器 |
| 国际贸易数据已发布 | 经现有 SSH 连接查询世界银行的年度贸易指标，按国家和年份筛选，标注来源、统计年度和数据集更新日期 | 正式包验证跨国家、年份和暂无数据场景，抓包确认只连接工作台服务器 |
| 按需资源已发布 | 从服务器目录选择公开接口并按时间、项目或关键词获取结果，支持保存 JSON | 生产接口验证真实数据，真机验证取数、查询、保存和原有数据入口 |
| 贸易及物流资源已发布 | 从服务端目录加载 RSS、Atom 和 CSV，支持关键词及 UTC 日期筛选，分别限制预览和导出规模 | 真机验证三种官方来源和所选日期的 CSV 内容，原有资源入口通过回归 |
| 资讯优先已发布 | 默认读取要闻，按时事、经贸、物流和其他来源分组，汇率作为独立参考 | 真机验证默认加载、分组切换和原有下载及指标功能 |
| 按实际使用完善输入 | 复用已有的快捷提示和草稿编辑。根据使用频率增加少量一键填入的常用提示，如检查服务、总结本轮进展 | 点选后可编辑。保留原草稿，用户主动发送后才创建任务 |

连接、任务和审批复用现有状态及事件。代码调整随功能落地，优先让会话、回执、审批和服务器状态在进入界面前完成解析，并为状态切换补回归。若实际使用频繁错过审批或任务结果，再验证后台通知、长时间待机和耗电。

## 如何发现应用场景

先回放最近一次移动审批、一次找历史结果和一次服务状态检查。记录从打开 APP 到完成的操作、耗时和卡住的位置，用同一场景复测。下面的开发顺序依据现有入口和操作摩擦，真实使用频率用两周的简短记录校正。

| 记录项 | 提问 |
| --- | --- |
| 触发与目标 | 在什么情况下拿起手机？要看到什么结果才算处理完？ |
| 现有路径 | 打开了哪些页面？哪个入口重复打开，哪个结果难找？ |
| 代价与风险 | 花了多久？是否发生等待、中断、误批、重复提交或资料丢失？ |
| 证据与试验 | 同类问题出现几次？用现有界面做一次小改动，能否少走一步或避免一次失败？ |

优先验证重复出现或处理失败会影响工作的流程。记录只需包含任务类型、点击次数、耗时和结果。先比较找到会话、处理审批和判断服务异常这三条路径。

### 第一轮待验证的场景

- **回到 APP 继续跟进。** 直接找到任务结果、待审批请求或正在编辑的草稿。用定位耗时、点击次数和误重发次数衡量。
- **查找做过的工作。** 用关键词、项目和状态找到旧会话，直接打开结果。用首次搜索命中率和是否需要手动翻页衡量。
- **判断服务异常。** 先查看采集时间、异常服务和最近错误。用 APP 内能否判断故障是连接问题还是服务问题衡量。
